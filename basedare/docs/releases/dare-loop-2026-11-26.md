# Dare Loop release acceptance — November 26, 2026

The existing visual system, Nodes, full map, advanced routes and backend are retained. The public entry is Dares, Watch and Profile. Counts reflect only recorded funded, eligible open Dares; existing paid assignment is one slot per Dare, not a new multi-winner payment rail. Watch uses the existing reviewed media surface.

Every public Dare uses `/dare/<shortId>` on the production domain, with native share, QR SVG and a printable sticker. Historical links must state actual availability. No payment is triggered by a scan.

For phone video, the browser soft-limits duration to 60 seconds and direct upload to 120 MiB. A signed, expiring Pinata ticket is bound to the authorized Dare, accepted delivery terms, agreed media metadata and exact storage receipt. The existing manual verification/settlement rail remains the authority. The browser duration limit is not an independent server-side proof of duration; review the actual recording. Photo briefs retain their existing delivery path. Optional BaseClips permissions do not affect proof review or payment.

Release gates:

- On a real phone, post a genuine funded Dare, scan the downloaded QR on a second phone, confirm the exact details, authenticate/claim, upload a camera recording (including a file over 4.5 MB), verify via the assigned poster/reviewer, and reconcile actual payout. Test denial, offline retry, oversized/malformed files, expiry and duplicate submission. Do not fund or settle an actual test without authorization.
- When separately configuring BaseClips, set the same tenant and new read-only export secret on the server and authorized local bridge; use the existing separate local HMAC secret and incoming folder. Verify only valid, approved, separately consented footage enters the queue. Withdraw and verify queued jobs stop. The worker produces a branded draft; existing exact-output creator review still governs publication. No automatic platform post or payout is enabled.
- No 48-hour automatic approval, GCash settlement, multi-winner or first-valid open race is certified by this increment. Keep existing assigned single-slot review and actual payment accounting until those mechanisms are separately proven.
